How Cars24 scales conversations and builds faster with OpenAI

Original Link

TL;DR

OpenAI 发布 Cars24 案例：这家汽车交易平台用 voice/chat agents 覆盖买车、卖车、融资、回访和售后，官方给出的结果是每月处理 100 万+ conversation minutes、客服 resolution rate 提升 50%、关键服务流程 turnaround time 降低 80%，并通过 AI re-engagement 挽回 12% 原本流失的 seller leads。内部侧，Cars24 还把 Codex 和 ChatGPT Enterprise 推到约 600 名员工，日活达到 85% 到 90%。

Key Points

  • 外部 agent 场景很完整：从 lead qualification、test drive booking、financing support 到售后 follow-up，覆盖整条车交易链路而不只是单一客服入口
  • 指标里最有业务味道的是 12% lost seller leads recovery，这说明 agents 不只省人工，还直接作用在中后漏斗转化
  • Cars24 把 Codex 嵌进 software development lifecycle：PM 用它生成和细化 Linear tickets，工程团队把 Codex 挂进 bug reports，自动汇总 GitHub 进展
  • 文章还展示了 agentic workflows 向 finance、investor relations、采购审批等部门扩散，甚至出现连接 Slack、Gmail、WhatsApp 的 chief of staff agents
  • 整体信号是 OpenAI 不再只卖模型，而是在卖“agents + Codex + org workflow redesign”的 operating layer

Why It Matters

这类案例的价值在于它把 agent 产品从 demo 拉回到组织流程：前台是高频对话自动化，后台是 Codex 驱动的内部执行和跨部门工具化。对关注 agent ROI 的人来说，这比泛泛的 adoption 叙事更接近真实落地样本。

My Take

这是偏商业案例的官方材料，但细节比一般客户故事扎实，尤其是把 Codex 放进 Linear / GitHub / bug 流里这一段。需要保留的怀疑同样明确：所有效果指标都是自报，没有对照组和成本拆解。不过它至少说明，大公司正在把 coding agent 从“工程师个人工具”升级为跨团队的 workflow substrate。

ChatGPT is now a partner for your most ambitious work

Original Link

TL;DR

OpenAI 发布 ChatGPT Work：一个能跨 apps/files 行动、长时间保持项目上下文、把目标拆成步骤并产出 sheets/slides/docs/web apps 的 agent。它内置 Codex technology，由 GPT-5.6 驱动，定位从问答助手升级为工作执行伙伴。

Key Points

  • ChatGPT Work 可跨 web、mobile、desktop 和用户文件/应用收集信息并产出完成品
  • 内置 Codex technology；OpenAI 称 Codex 每周已有 500 万用户，其中 100 万用于非软件开发工作
  • 支持长达数小时的 complex projects，可跟踪进度、向用户提问、改变方向并请求关键操作审批
  • 示例包括预算 variance analysis、campaign brief、sales meeting prep、Scheduled Tasks 自动更新 docs/slides
  • 强调组织安全与治理，明显对标 Claude Cowork / enterprise agents

Why It Matters

这是 OpenAI agent 产品线的重要扩展：Codex 不再只是 coding agent，而是成为一般办公 agent 的底层执行技术。它把 ChatGPT 从 conversational interface 推向 cross-app workflow executor。

My Take

这篇很重要。ChatGPT Work 的方向和 Claude Cowork/Claude Code converging：都在抢“能在真实工具里完成工作”的入口。关键挑战会是权限、安全、可追溯、失败恢复和用户信任。产品承诺很大，真实体验需要重点观察。
