Claude Fable 5 and Claude Mythos 5

Original Link

TL;DR

Anthropic 发布 Claude Fable 5 和 Claude Mythos 5，这是首个 Mythos-class 模型。Fable 5 面向大众，但通过 classifier 在 cybersecurity、biology/chemistry、distillation 三个领域 fallback 到 Opus 4.8；Mythos 5 则通过 trusted access program 提供给政府和企业合作伙伴，safeguards 更少。定价 $10/$50 per million tokens，比 Mythos Preview 便宜一半以上。

Key Points

  • Fable 5 在 coding、vision、long-horizon tasks 上达到 SOTA，能 autonomous 完成 Pokémon FireRed、Factorio 等复杂任务，Stripe 报告其将 50M 行 Ruby codebase migration 从两个月压缩到一天
  • Mythos 5 在 protein design 和 genomics research 上表现突出，能 autonomous 执行 drug design 全流程，在 14 个 protein targets 中有 9 个产生 strong candidates
  • Safety 机制：classifier 检测到敏感 query 会自动 fallback 到 Opus 4.8，平均触发率 <5% sessions，external red-teaming 1000+ hours 未发现 universal jailbreak
  • 新 data retention policy：Mythos-class models 强制 30 天留存，仅用于 safety 目的，不用于训练
  • Subscription 用户 6/9-6/22 免费使用 Fable 5，之后需 usage credits，API 和 consumption-based plans 全量开放
  • Trusted access program 将扩展到 biology researchers，提供 biology safeguards 移除版本

Why It Matters

这是 Anthropic 首次将 Mythos-class capabilities 开放给大众，标志着 frontier model 安全部署的新范式：通过 classifier + fallback 机制而非简单拒绝来平衡 capability 和 safety。对 agents 和 Claude Code 用户而言，Fable 5 的 long-horizon reasoning 和 autonomous capability 是质的提升。对中国读者而言，distillation safeguard 和 30-day retention policy 值得关注——这直接影响了数据合规和模型能力获取策略。

My Take

Fable 5 的 classifier + fallback 方案是务实的 compromise，但 5% 的 fallback 率和 false positives 仍是实际使用中的 friction。从 benchmark 和 early feedback 看，Fable 5 在 coding 和 research tasks 上确实领先 Opus 4.8 一个档次，尤其是 long-horizon autonomous work。但 subscription 的 rolling availability 说明 capacity 仍是瓶颈。Mythos 5 的 trusted access program 是典型的 controlled release 策略，biology 领域的开放值得关注——这可能成为 life sciences research 的 game changer。整体来看，Anthropic 在 safety 和 capability 的平衡上比 OpenAI 更谨慎，但 release 节奏明显加快。

Introducing Claude Opus 4.8

Original Link

TL;DR

Anthropic 发布 Claude Opus 4.8，定价不变，在 coding、agentic tasks、reasoning 等 benchmarks 上全面超越 Opus 4.7。同步推出 Claude Code 的 dynamic workflows（支持大规模并行 subagents）、effort control 功能，以及更便宜的 fast mode。Alignment 表现接近 Mythos Preview，honesty 显著提升。

Key Points

  • Opus 4.8 在 Terminal-Bench 2.1 达 87.2%（vs GPT-5.5 的 83.4%），OSWorld-Verified 84.1%，Legal Agent Benchmark 首破 10% all-pass standard——agentic 能力是本次升级核心
  • Honesty 提升 4 倍：更少 unsupported claims，更主动 flag 代码缺陷；misaligned behavior rate 显著下降，alignment 水平接近 Claude Mythos Preview
  • Claude Code 新增 dynamic workflows：单 session 可跑数百 parallel subagents，支持 codebase-scale migrations，面向 Enterprise/Team/Max 用户
  • Effort control 功能上线：用户可调节模型投入程度（low/extra/max），Opus 4.8 默认 high effort，xhigh/max 适合异步长任务
  • Fast mode 速度 2.5×，价格降至之前的 1/3；API 支持 messages array 内的 system entries，可 mid-task 更新指令
  • 预告 Mythos-class model 将在数周内发布，Project Glasswing 已扩展至约 150 家组织用于网络安全场景

Why It Matters

这是 Opus 系列的一次扎实迭代，agentic reliability 和 honesty 的提升直接解决了开发者痛点。Dynamic workflows 让 Claude Code 从单点助手升级为可编排大规模任务的 agent orchestrator，对 Devin、Cursor 等 ecosystem 是重要利好。Alignment 改进意味着 Anthropic 在 capability 和 safety 两条线上都在稳步推进。

My Take

Opus 4.8 不是 paradigm shift，但是一次高质量的 incremental release——benchmark 提升实在，功能更新务实。Dynamic workflows 和 effort control 是正确方向，说明 Anthropic 在 product 层面开始认真思考 agent orchestration 和 cost/quality tradeoff。值得关注的信号：1) honesty/alignment 被放在显眼位置，是 Anthropic 差异化叙事；2) Mythos 预览版已跑在网络安全场景，说明 frontier model 的 cyber safeguards 是 release bottleneck；3) fast mode 降价 3 倍是在为更高 effort 模式下的 token 消耗做对冲。对中文用户而言，如果你在用 Opus 做 coding 或 agent 开发，这次升级值得立刻切换。
